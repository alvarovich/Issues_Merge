## Introducción

Compartir piso es una opción cada vez más habitual, especialmente entre estudiantes y jóvenes que buscan independizarse. Sin embargo, gestionar los gastos comunes, como el alquiler, el agua, la electricidad o internet, puede resultar complicado, sobre todo cuando se producen cambios de inquilinos.

Para facilitar esta tarea nace **Split Mate**, una aplicación diseñada para organizar y repartir los gastos de una vivienda compartida de forma sencilla, rápida y transparente.

Su principal característica diferenciadora es el **sistema de prorrateo automático**, que permite recalcular los gastos cuando un inquilino abandona la vivienda, teniendo en cuenta el tiempo de estancia y redistribuyendo los importes correspondientes entre los compañeros que permanecen en el piso.

Con Split Mate buscamos simplificar la gestión económica de los pisos compartidos, evitar cálculos manuales y reducir posibles conflictos entre compañeros, consiguiendo un reparto de gastos más justo y organizado.
